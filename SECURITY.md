# Security Policy

`burn-speech-training` is a reference training crate, not a hosted service. Most
issues will be normal bugs, reproducibility problems, or documentation gaps.

## Supported Versions

Security fixes target the current `main` branch and any published release.

## Reporting A Security Issue

Do not attach private audio, private transcripts, model weights, API keys, or
dataset credentials to public issues.

For security-sensitive reports, use GitHub private vulnerability reporting if it
is available for this repository. If it is not available, open a public issue
with only a short non-sensitive summary and ask for a private contact path.

For normal bugs, crashes, and incorrect documentation, open a regular GitHub
issue with the command you ran, the Rust version, the feature flags, and whether
the input audio is public or synthetic.
